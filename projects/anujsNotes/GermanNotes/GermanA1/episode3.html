German Numbers (Zahlen)

German numbers follow a logical system. Once you learn the core building blocks (0–19 and the tens), you can construct any number up to 999,999 from patterns alone. The main surprise is that from 21 onwards, Germans say the ones digit before the tens digit.

📖
The Big Rule: Ones Before Tens
21 = einundzwanzig (one-and-twenty)
47 = siebenundvierzig (seven-and-forty)
99 = neunundneunzig (nine-and-ninety)

Pattern: ones + und + tens — written as one word!

Constructing compound numbers (21–99)

✏️
Examples
21 = ein + und + zwanzig = einundzwanzig
32 = zwei + und + dreißig = zweiunddreißig
47 = sieben + und + vierzig = siebenundvierzig
68 = acht + und + sechzig = achtundsechzig
99 = neun + und + neunzig = neunundneunzig
💡
Two Important Rules
1. Inside a compound number, use ein, not eins: → einundzwanzig (not einsundzwanzig)
2. Numbers below one million are written as one word: siebenundvierzig, never sieben und vierzig.
