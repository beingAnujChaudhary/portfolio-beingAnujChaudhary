German Numbers (Zahlen)

German numbers become much easier when you learn them as a construction system rather than as an endless list. The main surprise is that from 21 to 99, German normally says the ones before the tens.

Numbers 0-12

These are the essential building blocks and should be memorized.

  • 0: null
  • 1: eins
  • 2: zwei
  • 3: drei
  • 4: vier
  • 5: fünf
  • 6: sechs
  • 7: sieben
  • 8: acht
  • 9: neun
  • 10: zehn
  • 11: elf
  • 12: zwölf

Numbers 13-19

The general pattern is: ones + zehn.

  • 13: dreizehn
  • 14: vierzehn
  • 15: fünfzehn
  • 16: sechzehn (drops the s of sechs)
  • 17: siebzehn (drops the en of sieben)
  • 18: achtzehn
  • 19: neunzehn

The tens

  • 20: zwanzig
  • 30: dreißig (uses -ßig, not -zig)
  • 40: vierzig
  • 50: fünfzig
  • 60: sechzig
  • 70: siebzig
  • 80: achtzig
  • 90: neunzig
  • 100: hundert
  • 1,000: tausend
  • 1,000,000: eine Million (a noun)

Numbers 21-99

For a non-zero ones digit: ones + und + tens

  • 21 = ein + und + zwanzig = einundzwanzig
  • 32 = zwei + und + dreißig = zweiunddreißig
  • 47 = sieben + und + vierzig = siebenundvierzig
  • 68 = acht + und + sechzig = achtundsechzig

Rule 1: Use ein, not eins, inside a compound number.
Rule 2: Write the complete number as one word when it is below one million.
